# Proposed RFCs

This directory contains durable proposals that are open for review. A proposal
is numbered only when its scope and alternatives are ready for discussion.

Proposed RFCs do not override accepted RFCs, public language contracts, or
verified implementation behavior. Implementation planning remains under
`.codex/plans/`; a task plan is not promoted here merely because it is large.

When a proposal is accepted, move it to `../accepted/`, set
`Status: Accepted`, and add it to the RFC index. Rejected or withdrawn
proposals should record that outcome before they are removed or retained for
historical value.
